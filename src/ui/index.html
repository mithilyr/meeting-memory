Team timeline

Everything the memory holds for one team, meeting by meeting. Code works out what is current and what was replaced from the meeting order.

Pre-meeting brief

Built only from meetings that have already happened. Every point carries its source.

Add meetings

Upload new transcripts, then refresh. Refresh reads only what is new: it indexes the files, pulls out decisions and actions, and updates what is current. Files already in memory are skipped.

Read-only demo

This hosted copy holds the 138 meetings and can't take new ones, so visitors can't change the memory or use up its quota. To add meetings, run it locally (README). New uploads go through the same checks: screening for planted instructions, quote checks and the truth audit.

File names must be the meeting id: team id plus meeting letter, for example TS3013a.txt. Each turn is a line like "00:01:06 Speaker B" followed by the words.
