How it works

Every meeting is read once. Every question works on one project.

Each question touches one project, so its cost is the same at 100 meetings or 10,000.

Model or code

If there is one right answer, it is plain code.

Plain code

  • Parsing, ids, incremental ingest
  • Meeting order and what is current
  • Quote checks, word for word
  • The brief's cutoff, the output format
  • Auditing the model's notes: 16 figures nobody said, 1 currency wrong

Model

  • Reading messy, overlapping speech into events
  • Writing a clear answer from given evidence
  • Deciding it needs another search
