Walkthrough of my build for the Catalist Agentic AI Intern build test: an agent that turns 138 real meeting
transcripts (AMI Meeting Corpus) into memory you can question. Every answer is checked word for word
against the transcript, and the agent says "not discussed" instead of guessing.
